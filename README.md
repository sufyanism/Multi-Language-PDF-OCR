# Multi-Language PDF OCR
A powerful browser-based OCR application that extracts text from scanned or image-based PDF documents while preserving the original language and script.
This project supports multiple world languages including:
- English
- Hindi
- Punjabi
- Urdu
- Tamil
- And many more

## Features
- Extract text from scanned PDFs
- Supports multiple world languages
- Preserves original script and language
- OCR for image-based PDFs
- Live extraction progress bar
- Download extracted text as TXT file
- Clean and responsive UI
- Browser-based OCR
- No backend required

## Technologies Used
- HTML5
- CSS3
- JavaScript
- jQuery
- PDF.js
- Tesseract.js
- FileSaver.js

## How It Works
1. Upload a scanned PDF
2. PDF.js converts pages into images
3. Tesseract.js performs OCR
4. Extracted text appears live
5. Download extracted text file
